# Shipr

Shipr is **AI shipping config and release memory**. It is not a deploy runner.

- Config: `.shipr/product-release-model.json`
- Ledger: `.shipr/release-attempts/`
- Sibling: [testr](https://github.com/eidos-agi/testr) supplies `test_commands` absorbed as `proof_commands`

Canonical CLI: Go (`go install github.com/eidos-agi/shipr/cmd/shipr@latest`).
